# 🧬 DNA Bioinformatics Visualizer

一个基于原生 JavaScript 构建的 DNA 序列可视化分析工具。

## 🚀 项目简介

该项目支持从本地文件或 NCBI API 获取 FASTA 序列，
并进行 GC 含量分析、滑动窗口计算以及 Canvas 可视化展示。

## ✨ 功能特性

- FASTA 文件解析
- DNA 序列长度统计
- GC 含量计算
- 滑动窗口 GC 曲线绘制（Canvas 实现）
- 反向互补链生成
- 搜索历史记录（localStorage）

## 🛠 技术栈

- HTML
- CSS
- Vanilla JavaScript (ES6+)
- Canvas API
- Fetch API


## ▶️ 使用方式

1. 克隆项目
2. 打开 `index.html`
3. 输入 DNA 序列或上传 FASTA 文件
